                            │

✅  Validated using Auth0's public key
✅  Contains user roles and info
```

## 4️⃣ COMPLETE REQUEST-RESPONSE CYCLE

### User Logs In:
```
1. Frontend → Auth0 login page
   └─ User provides credentials

2. Auth0 → Frontend
   └─ Issues JWT token (containing user info + roles)

3. Frontend → API Gateway GET /api/me
   Headers: Authorization: Bearer {JWT}
   └─ Validates JWT
   └─ Extracts user_id, email, roles
   └─ Saves user to MySQL
   └─ Returns user info

4. Frontend → Routes to /chat or /admin based on role
```

---

### User Sends Chat Message:
```
1. Frontend → API Gateway POST /api/chat
   Body: { question, conversation_id }
   Headers: Authorization: Bearer {JWT}

2. API Gateway:
   ✓ Validates JWT → Extract user_id
   ✓ Creates/fetches conversation (MySQL)
   ✓ Saves user message to MySQL
   
3. API Gateway → RAG Service POST /internal/query
   Body: { question }
   Headers: X-Internal-Secret: {SECRET}
   
4. RAG Service:
   a) Hybrid Search:
      - Semantic: vector database (Chroma)
      - Lexical: BM25 index
   
   b) Reranking:
      - Score relevance with Claude LLM
      - Keep top 5 documents
   
   c) Generation:
      - Create prompt with context
      - Call Claude LLM
      - Generate answer
   
   └─ Returns: { answer, context, timings }

5. API Gateway:
   ✓ Saves assistant message to MySQL
   └─ Returns { answer, conversation_id } to Frontend

6. Frontend:
   └─ Displays answer to user
```

---

### Admin Uploads Document:
```
1. Frontend → API Gateway POST /api/admin/documents
   Body: File upload
   Headers: Authorization: Bearer {JWT}

2. API Gateway:
   ✓ Validates JWT
   ✓ Checks if user is admin (role == "admin")
   ❌ If not admin → 403 Forbidden

3. API Gateway → Document Service POST /internal/documents
   Body: File
   Headers: X-Internal-Secret: {SECRET}

4. Document Service:
   ✓ Parse document (PDF, DOCX, TXT)
   ✓ Split into chunks
   ✓ Create embeddings
   ✓ Store in Chroma (vector database)
   └─ Returns: { document_id, chunks_count }

5. API Gateway → Returns to Frontend
```

├─────────────────┼───────────────┼───────────────┼──────────────┤

│ (S2S)           │ (X-Internal)  │               │              │

JWT Structure:
{
  "sub": "auth0|user123",           ← user_id
  "email": "user@example.com",
  "name": "John Doe",
  "https://myapp.example.com/roles": ["admin"],  ← ROLES
  "iat": 1234567890,                ← issued at
  "exp": 1234654290,                ← expiration
  "aud": "https://your-api-audience",
  "iss": "https://your-domain.auth0.com/"
}
```

## 7️⃣ RAG PIPELINE STAGES (IN DETAIL)

```
INPUT: "What is machine learning?"
│
├─ STAGE 1: RETRIEVAL (k=8)
│  ├─ Semantic Search (Vector similarity)
│  │  └─ Query: Convert to embedding
│  │  └─ Search Chroma: Find closest 8 vectors
│  │  └─ Return: Top 8 semantically similar chunks
│  │
│  └─ Lexical Search (BM25 keyword matching)
│     └─ Tokenize query: ["machine", "learning"]
│     └─ BM25 index lookup
│     └─ Return: Top 8 keyword-matching chunks
│
├─ Merge & Deduplicate using RRF
│  └─ Return: 8 merged candidates
│
├─ STAGE 2: RERANKING (top_k=5)
│  └─ For each of 8 candidates:
│     ├─ Score relevance using Claude LLM
│     └─ Get relevance_score (0-1)
│  │
│  └─ Sort by score, keep top 5
│
├─ STAGE 3: GENERATION
│  ├─ Build Prompt:
│  │  ├─ Context: [top 5 reranked chunks]
│  │  └─ Question: "What is machine learning?"
│  │
│  └─ Call Claude LLM:
│     ├─ model: "claude-3-sonnet-20240229"
│     ├─ max_tokens: 1024
│     └─ Return: Generated answer
│
└─ OUTPUT: "Machine learning is a subset of AI..."
```

## 9️⃣ ENVIRONMENT VARIABLES EXPLAINED

```
# Auth0 Configuration
AUTH0_DOMAIN              = "your-tenant.auth0.com"
                          → Used to fetch JWT signing keys
                          → Used to validate token issuer

AUTH0_AUDIENCE            = "https://your-api-audience"
                          → JWT must have this audience claim
                          → Prevents token misuse across apps

# Service URLs
RAG_SERVICE_URL           = "http://127.0.0.1:8001"
                          → Where to call for RAG queries

ADMIN_SERVICE_URL         = "http://127.0.0.1:8003"
                          → Where to call for admin operations

DOCUMENT_SERVICE_URL      = "http://127.0.0.1:8002"
                          → Where to call for document processing

# Authentication
INTERNAL_SERVICE_SECRET   = "your-shared-secret"
                          → Passed in X-Internal-Secret header
                          → Used for service-to-service auth

# Database
DATABASE_URL              = "mysql+pymysql://user:pass@host/db"
                          → API Gateway MySQL connection

# LLM
ANTHROPIC_API_KEY         = "sk-ant-..."
                          → Claude API key
```

## Summary

| Aspect | Details |
|--------|---------|
| **JWT Generator** | Auth0 (external SaaS) |
| **JWT Validator** | API Gateway (using Auth0's public key) |
| **Frontend Auth** | JWT token in Authorization header |
| **Service-to-Service** | Shared secret in X-Internal-Secret header |
| **Role Check** | From JWT `https://myapp.example.com/roles` claim |
| **Chat Flow** | Frontend → API Gateway → RAG Service → LLM |
| **Data Storage** | MySQL (conversations/messages), Chroma (vectors) |
| **RAG Pipeline** | Retrieve → Rerank → Generate |
| **All Ports** | Frontend:5173 → APIGateway:8000 → Microservices |
